# ai-systems-experiments

Reproducible experiments on how AI systems work, break and cost money.
Companion repository to the YouTube channel **Engr Boltzmann**.

## Rules

1. **Own systems only.** I test only systems I own. No attacks on third-party products.
2. **Measured, not estimated.** Every claim comes from a measured result.
3. **Full reporting.** Each experiment records hardware, software versions and the number of repeated runs.
4. **Reproducible.** Each experiment has its own folder with code, instructions and results.

## Test machine

- CPU: Intel Core i7-7600U (2 cores)
- RAM: 16 GB DDR4-2133
- GPU: none used locally (Intel HD 620, no CUDA)
- Cloud GPUs are rented only for work that needs them, and are labelled in the results.
